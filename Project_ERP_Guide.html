TrackBells Drag Chain Factory Operations Guide

Official ERP Role Responsibilities & Database Flow Matrix

Project Scope & Production Environment

This document represents the live production roles and data workflows configured in the TrackBells Drag Chain ERP system. It outlines the specific capabilities of each of the 6 roles implemented in the codebase (Gate Guard, Supervisor, Quality Checker, Store Manager, Sales Officer, and System Admin) for processing raw materials (Nylon Granules, Steel Pins, Links) into finished drag chains (Models: STR-35 and STR-26).

🚛
Gate Guard
Inward Gate Registry
👤 Core Duty
Log incoming supply vehicles carrying raw materials at the factory entry gate.
📝 Data Added
Inward Gate Log: Invoice/Bill No., Vendor Name, Vendor Contact, Material Type (Nylon Granules, Steel Pins, etc.), Quantity, Unit, Driver Name, and scanned Invoice Document.
👁️ Visibility
Directly appears on the Supervisor dashboard (for physical verification) and the Store Manager dashboard in real-time.
⚡ Action Taker
Supervisor reviews the entry to either Approve (Pass) or Reject the gate inward log.
⚙️
Supervisor
Production & Machinery
👤 Core Duty
Manage moulding & extrusion machines, approve gate entries, and log daily production targets.
📝 Data Added
Production Log: Assigns pending Sourcing Build Orders to specific machines (e.g., Moulding Machine #1) and logs daily manufacturing output (Shots Fired) and raw material usage.
👁️ Visibility
Dispatched finished products are visible as Work-in-Progress (WIP) on the Store Manager dashboard for godown sorting.
⚡ Action Taker
Store Manager receives the WIP dispatch and completes the assembly step to increment finished goods stock.
🔍
Quality Checker
QC Inspections
👤 Core Duty
Audit arriving raw materials for defects and upload supplier invoices for verification.
📝 Data Added
QC Invoice Log: Invoice Number, Vendor Name, Total Quantity, Defective Quantity, Rejected Quantity, Quality Score (out of 100), comments, and uploaded Invoice Document.
👁️ Visibility
Appears in the QC Verification queue of both the Sales Officer and Store Manager dashboards.
⚡ Action Taker
Store Manager or Sales Officer clicks Verify.
* Compliance Rule: The Quality Checker is blocked from verifying their own logs to prevent collusion.
📦
Store Manager
Godown & Inventory
👤 Core Duty
Manage Godown warehouse inventory (Racks/Bins), assemble products, and track stock shortages.
📝 Data Added
Warehouse Logs & Shortages: Assembly details (rack/bin locations assigned to items) and registers Shortage Logs for materials running low.
👁️ Visibility
Unified stock counts and shortage alerts are instantly visible on the Sales Officer and Supervisor dashboards.
⚡ Action Taker
Sales Officer reviews shortage reports and places raw material Purchase Orders.
🛒
Sales Officer
Sales & Sourcing
👤 Core Duty
Create customer build orders, place procurement purchase orders, and verify QC invoices.
📝 Data Added
Order Management & Procurement: Creates Build Orders for finished drag chains (e.g., STR-35 Chain - 500m) and issues Purchase Orders for shortage materials.
👁️ Visibility
Build Orders populate the Supervisor's queue; Purchase Orders/Shortages are shared with the Store Manager.
⚡ Action Taker
- Supervisor starts production on the Build Order.
- Sales Officer dispatches completed orders, auto-deducting stock.
🛡️
System Admin
Platform Control
👤 Core Duty
Manage organization branding settings, update styling parameters, and manage user accounts.
📝 Data Added
Configurations & Users: Creates and deactivates users, manages permissions, sets primary theme colors, and configures active sidebar menu visibility options.
👁️ Visibility
Branding options and page layouts dynamically update the theme configuration context across all users' screens.
⚡ Action Taker
Changes made by the Admin immediately enforce access permissions and style branding globally.

ERP Database Flow & Lifecycle Matrix

Initiating Role (Created By) Logged Transaction (Data Record) Target Dashboards (Visible To) Assigned Responder (Action Taker) Workflow & Database Outcome
Gate Guard Gate Inward Log (e.g. Nylon Granules - 1000 kg) Supervisor, Store Manager Supervisor (Approves/Passes log) Records the supply vehicle presence; sets inward status to `passed` for physical receipt.
Sales Officer Build Order (e.g. Drag Chain STR-35 - 300 pcs) Supervisor, Store Manager Supervisor (Assigns machine & runs build) Sourcing request is registered; sets machine to `running` state and locks production target.
Supervisor Daily Production Dispatch (output items from machine) Store Manager Store Manager (Completes Assembly) Generates Work-in-Progress (WIP) logs; moves inventory into store warehouse queue.
Quality Checker QC Invoice Log (e.g. scanned tax invoice document) Sales Officer, Store Manager Sales Officer or Store Manager Uploads invoice file and quality score. Once verified, increments corresponding raw material inventory levels.
Store Manager Inventory Shortage Log (e.g. Steel Pins Low Stock) Sales Officer, Supervisor Sales Officer (Issues PO) Notifies sourcing team of stock deficit; triggers external vendor purchase order flow.
Store Manager WIP Assembly Completion (assigned to Racks/Bins) Sales Officer, Admin Sales Officer (Dispatches Finished Order) Updates customer order state to `Ready`; increments finished goods stock, then decrements on dispatch.
