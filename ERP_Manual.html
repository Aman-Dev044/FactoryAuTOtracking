🔍 Detailed Step-by-Step UI Navigation & Usage

1️⃣ Pitch <> Link Auto Calculation & Order Code Integration

Client Requirement (Paramveer Singh - TrackBells):
"As per model number, number of links will be calculated: per meter / pitch length. Pitch will be fixed. Number of links will vary basis model number. 1000mm (1 meter) ÷ pitch length in mm = number of links, which will be added to our order model code."

📍 UI Location:

  1. Click "🛒 Sales & Orders" (/sales) in the left sidebar.
  2. Select the "Sales Pipeline & Funnel" tab.
  3. Click the "+ New Lead / Order" button (or click "✏️ Edit" on an existing order).
  4. Scroll down to the "⚙️ Drag Chain Technical Configuration" section.

🖱️ Step-by-Step Usage:

  1. Select Model Number: Pick a Drag Chain model from the dynamic dropdown (e.g. S 10, S 15, S 20, S-25.1, S-35.1, S-35.2, etc.).
  2. Auto Pitch & Links Assignment: The Pitch (mm) and Calculated Links automatically load from the database master sheet:

    Model Number

    Fixed Pitch (mm)

    Links / Meter (1000 ÷ Pitch)

    Standard Length (mm)

    Base Rate / Meter (₹)
    S 1016 mm63 Links1008 mm₹450
    S 1524 mm42 Links1008 mm₹650
    S 2035 mm29 Links1015 mm₹850
    S-21.133 mm31 Links1023 mm₹900
    S-25.146 mm22 Links1012 mm₹1,200
    S-29.122 mm46 Links1012 mm₹1,350
    S-35.125 mm40 Links1000 mm₹1,500
    S-35.256 mm18 Links1008 mm₹1,650
    S-42.167 mm15 Links1005 mm₹1,950
    S-45.167 mm15 Links1005 mm₹2,200
    S-56.191 mm12 Links1092 mm₹2,700
    S-6095 mm11 Links1045 mm₹3,100
    S-80.1112 mm9 Links1008 mm₹4,200
  3. Exact Calculation Formula:
    Total Links = Math.ceil( Length in mm ÷ Pitch in mm )
    Length (mm) = Quantity in Meters × 1000
    Example: Model S-25.1 with Pitch 46mm → Math.ceil(1000 ÷ 46) = 22 Links per meter.
  4. Order Model Code Auto-Integration:

    The system automatically builds the standardized 8-block Order Code and embeds the calculated link count in the 5th block:

    Format:  [MODEL]-[WIDTH]-[RADIUS]-[TYPE]-[NO_OF_LINKS]-[LENGTH]-[BRACKET]-[ACCESSORIES]
Example: S2425.1-150-R125-OP-22-1000-B.25.1-HS.25.1
    • S2425.1 → Model Series
    • 150 → Inner Width (mm)
    • R125 → Bending Radius
    • OP → Open Type (or CL for Closed, SC for Semi-Closed)
    • 22 → Auto-Calculated Number of Links
    • 1000 → Chain Length in mm
    • B.25.1 → Mounting Bracket Type (e.g. B.25.1, L.25.1, LSR.25.1.P, LSR.25.1.M)
    • HS.25.1 → Horizontal/Vertical Separator Accessories

2️⃣ Database-Driven Universal Model Info (Pitch & Pricing Manager)

100% Dynamic Architecture: No model specifications, pitches, links, or rates are hardcoded in the codebase. All specifications reside in MongoDB and can be managed directly by Admins from the UI.

📍 UI Location:

  1. Click "👑 Universal Model Info" (/admin/universal-model-info) in the left sidebar under Admin Control.

🖱️ Step-by-Step Usage:

  1. Live Model Catalog: View all factory Drag Chain models with their fixed Pitch (mm), Rate per Meter (₹), Links per Meter, and Available Inner Widths.
  2. Add New Model: Click "+ Add Product Template" to introduce a new Drag Chain series without deploying new code.
  3. Edit Pitch or Price: Click "✏️ Edit" on any model row to adjust its fixed pitch or base pricing. Changes immediately reflect across the Sales Pipeline and quotation generator.

3️⃣ Auto Price Calculation & Fixed Base Price (Discount % Only)

📍 UI Location:

  • Inside the "+ New Lead / Order" modal → "💰 Pricing & Commercials" section.

🖱️ Step-by-Step Usage:

  1. Locked Base Rate: The Base Rate / Meter (₹) field is automatically loaded from the database (e.g. ₹1,200/m for S-25.1) and is locked (read-only) for sales executives.
  2. Automatic Gross Amount: Selecting 2.5 Meters automatically computes Gross Amount: ₹3,000 ($2.5 \times ₹1,200$).
  3. Sales Discount Control: Sales representatives enter the discount percentage in "Sales Discount (%)" (e.g. 10%).
    • Discount Amount: ₹300 ($₹3,000 \times 10\%$)
    • Taxable Amount: ₹2,700 ($₹3,000 - ₹300$)
    • GST Amount (18%): ₹486 ($₹2,700 \times 18\%$)
    • Grand Total (₹): ₹3,186 ($₹2,700 + ₹486$)

4️⃣ Auto-Generated Sequential Sales Order Number

📍 UI Location:

  • Inside the "+ New Lead / Order" modal when selecting Stage: "Sales Order".

🖱️ Step-by-Step Usage:

  1. Select "Sales Order" from the Stage dropdown.
  2. The Sales Order Number field auto-populates with the next sequential identifier (e.g., SO-2026-0001, SO-2026-0002).
  3. Manual entry is eliminated, preventing duplicate order numbering across tenants.

5️⃣ Sales Order Admin Approval Workflow

📍 UI Location:

  • Sales User View: 🛒 Sales & Orders → Order Table.
  • Admin User View: 🏠 Tracker Dashboard (/dashboard) or 🛒 Sales & Orders (/sales).

🖱️ Step-by-Step Usage:

  1. Order Creation by Sales: When a new Sales Order is submitted, it is tagged with a yellow ⏳ Pending Approval badge.
  2. Admin Action: Administrators see action buttons in the order row:
    • ✅ Approve: Approves the order, logs timestamp & admin identity, and updates badge to ✅ Approved.
    • ❌ Reject: Opens a modal to enter rejection remarks and updates badge to ❌ Rejected.

6️⃣ GST Number, Billing Address & Shipping Address (Same / Different Checkbox)

📍 UI Location:

  • Inside the "+ New Lead / Order" modal → "🏢 Customer Information & Tax Address" section.

🖱️ Step-by-Step Usage:

  1. Customer GSTIN: Enter the 15-character GSTIN (e.g., 07AAAAA0000A1Z5).
  2. Billing Address: Enter the full registered billing address.
  3. Checkbox: "Shipping Address is same as Billing Address":
    • When Checked (Default): The Shipping Address field is disabled and automatically mirrors Billing Address.
    • When Unchecked: A dedicated Shipping Address textarea appears for alternate site delivery.

7️⃣ Decimal Chain Length & Quantity in Meters (2.5 m)

📍 UI Location:

  • Inside the "+ New Lead / Order" modal → "Quantity (Meters / m)" field.

🖱️ Step-by-Step Usage:

  1. Enter any decimal quantity (e.g., 1.5, 2.75, 10.25 meters).
  2. The system dynamically converts meters to millimeters ($2.75\text{ m} = 2750\text{ mm}$) and calculates total links and pricing accurately without decimal rounding discrepancies.

8️⃣ Edit Approved Orders & Change History Audit Logs

📍 UI Location:

  • 🛒 Sales & Orders → Sales Pipeline Table rows.

🖱️ Step-by-Step Usage:

  1. Editing Approved Orders: Click the "✏️ Edit" button on any order row (even if status is Approved or Dispatched). Modify details and click "Save Changes".
  2. Viewing Audit Logs: Click the "🕒 Clock Icon" on any order row to view full history:
    • User Name & Role: (e.g., Ramesh Sharma — Sales Executive)
    • Timestamp: (e.g., 10-Sep-2026, 11:30 AM)
    • Changes Summary: (e.g., Quantity: 2.0m → 3.5m, Grand Total: ₹2,400 → ₹4,200)
    • Edit Reason / Note

9️⃣ Independent Dispatch Department (Restricted Access)

📍 UI Location:

  • Left sidebar: "🚚 Dispatch & Shipping" (/dispatch).

🖱️ Step-by-Step Usage:

  1. Role-Based Visibility: Sales Users and Gate Guards cannot see the Dispatch menu in the sidebar. Accessible only to Dispatch Manager, Store Manager, and Admin.
  2. 4-Stage Dispatch Workflow:
    • 🔧 Assemble Tab: Review incoming sales orders and stage components.
    • ⏸️ On Hold Tab: Place shipments on hold with mandatory justification.
    • 📦 Packing Tab: Record carton/box count and gross weight (kg).
    • 🚚 Dispatched Tab: Enter Courier Partner, AWB/Tracking #, upload LR (Lorry Receipt), and POD (Proof of Delivery).

🔟 Sales Confidential Logistics & Freight Terms

📍 UI Location:

  • 🛒 Sales & Orders → "+ New Lead / Order" modal → "🚚 Sales Confidential Logistics Details" section.

🖱️ Step-by-Step Usage:

  1. Freight Terms Options:
    • Paid by Us (paid_by_us): Freight cost covered by factory.
    • Paid by Client (paid_by_client): Client paid freight in advance.
    • To-Pay by Customer (to_pay): Freight payable upon delivery by customer.
    • Included in Invoice (included): Freight added to tax invoice lines.
  2. Logistics Fields: Enter Courier Partner (DTDC, BlueDart, SafeExpress, TCI, Trackon), AWB Number, Shipping Charges (₹), and Confidential Remarks.
  3. Data Privacy: These commercial logistics fields are automatically hidden from Dispatch personnel and Gate Guards.

1️⃣1️⃣ Tax Invoice vs Delivery Challan (Dual Tabs on Order Modal)

📍 UI Location:

  • Header of the "+ New Lead / Order" modal → Top Document Switcher Tabs.

🖱️ Step-by-Step Usage:

  1. Tab 1: 📄 Tax Invoice: Commercial billing with Invoice Number, Invoice Date, HSN Code (8483), GST Rate (18%), Inter-State (IGST) Toggle, and Payment Terms.
  2. Tab 2: 🚚 Delivery Challan: Goods movement without immediate billing: Challan Number, Challan Date, Transport Mode (Road/Rail/Air), Vehicle Number, E-Way Bill Number, LR Number, Receiver Name, and Dispatch Notes.

1️⃣2️⃣ Procurement Flow: Vendor Code → Quotation → 1-Click PO → Gate PO Approval

📍 UI Location:

  • Left sidebar: "📋 Purchase & Procurement" (/finance) and "🚛 Gate Operations" (/gate-guard).

🖱️ Step-by-Step Flow:

flowchart LR
    A["1. Vendors Master
(Auto VEN-0001)"] --> B["2. Add Quotation
(Auto VQ-2026-0001)"]
    B --> C["3. Click 'Generate PO'
(Auto PO-2026-0001 + PDF)"]
    C --> D["4. Gate PO Inward
(Auto-Fill & Verify)"]
  1. Step 1: Create Vendor Master: Go to Purchase & Procurement → "🏢 Vendors Master" → Click "+ Add New Vendor". System generates sequential Vendor Code (VEN-0001).
  2. Step 2: Enter Vendor Quotation: Go to "📜 Quotations" → Click "+ Add Quotation". System assigns VQ-2026-0001.
  3. Step 3: 1-Click PO Generation: On the quotation card, click "⚡ Generate PO" → converts to PO-2026-0001 and creates vendor PDF.
  4. Step 4: Gate Inward Verification against PO: In Gate Operations, select PO → details auto-fill → Guard verifies and approves entry.

1️⃣3️⃣ Purchase Store Inward/Outward & IN/OUT Stock Ledger

📍 UI Location:

  • Left sidebar: "📋 Purchase & Procurement" (/finance) → "🏢 Purchase Store & Godown" and "📖 IN/OUT Stock Ledger" tabs.

🖱️ Step-by-Step Usage:

  1. Inward Entry: Click "📥 Inward Stock" → enter material, qty, rack/bin, PO# → stock increases & green IN transaction logs in Ledger.
  2. Outward Entry: Click "📤 Issue to Production" → select material, qty, machine line → stock decreases & orange OUT transaction logs in Ledger.
  3. Stock Ledger: Real-time ledger showing material, remaining balance, PO/Bill reference, user identity, and date/time stamps.
